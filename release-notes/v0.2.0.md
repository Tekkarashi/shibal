## What's new

- **Shibal is now signed with its own private key.** Only releases from this project can install as a Shibal update, so nobody can pass around a fake one.
- **Coming from 0.1.x?** This one time, Android can't update over your old copy. Open Shibal → Settings → App update and follow the four steps (back up, download, uninstall, install and restore). It takes about two minutes and nothing is lost. Every update after this comes through the app again.
